# CodeAlpha Chatbot

## Project Description

This is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

## Features

* Responds to "hello"
* Responds to "how are you"
* Exits when the user types "bye"
* Displays a default reply for unknown messages

## Technologies Used

* Python
* VS Code

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

`python chatbot.py`

## Learning Outcomes

This project helped me understand Python functions, loops, conditional statements, and user input/output.
